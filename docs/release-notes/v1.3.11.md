# Release notes — v1.3.11

**Compare range:** https://github.com/Swamp-Ig/pizone/compare/v1.3.10...v1.3.11

## Since v1.3.10

### API v2 (new)

- Prefer the bridge's V2 API for reads when it returns useful data, and send writes through `iZoneCommandV2`. V2 data is normalized into the same V1-shaped caches, so the public API is unchanged (#35)
- Confirm V2 zone mode changes by reading them back, within fixed time limits, and yield between polling reads so queued commands are not held up by a full zone sweep. See [V2 zone mode confirmation](../v2-confirmation.md)
- Keep the zone setpoint when selecting AUTO mode over V2
- Validate V2 zone snapshots, and keep a zero airflow value instead of dropping it
- Correct the V2 sensor and fan enums against the vendor header
- Free Air: try the V2 `iSaveOn` command first and fall back to the V1 `FreeAir` endpoint if the bridge rejects it, remembering the result per controller
- Free Air status is now read from `iSaveEnable`/`iSaveOn`. Before, V2 bridges always reported it as off

### Fixes / hardening

- Allow controllers with no zones (unit-only systems). A negative zone count is still treated as a fault (#33, #34)
- Put a time limit on closing the discovery UDP transport. If the socket is not released within 1 s, abort it instead of hanging shutdown (Windows Proactor) (#41, #42)
- Document that setting a sleep timer can turn the unit on with some bridges
