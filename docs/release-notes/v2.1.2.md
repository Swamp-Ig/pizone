# Release notes — v2.1.2

**Compare range:** https://github.com/Swamp-Ig/pizone/compare/v2.1.1...v2.1.2

## Since v2.1.1

### Change the name a running controller follows

- New `DiscoveryService.set_host_name(uid, host)`. It sets the host name a running controller looks up again after a transport failure, for a caller that stores a new host for the controller without recreating it.
- An IPv4 `host` clears the name. The per-controller lookup cooldown is reset, so the next failure looks up the new name.
- It doesn't move the controller to a new address; `discover_by_host()` already does that. It does nothing for a UID without a running controller.
- No other changes.
