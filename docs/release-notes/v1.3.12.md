# Release notes — v1.3.12

**Compare range:** https://github.com/Swamp-Ig/pizone/compare/v1.3.11...v1.3.12

## Since v1.3.11

### V2 status data (new)

- Every V2 zone and system key now reaches the cache, so `dump_state()` and diagnostics include the full payload. Nested system groups (`UnitOpt`, `Temperzone`, `GasHeat`) are flattened to dotted keys such as `UnitOpt.RA`. The `LockCode` and `Pass` secrets are dropped and never cached
- New zone properties: `damper_position`, `damper_fault`, `sensor_fault`, `rf_signal`, `battery_level` and `sensor_type`, plus the `Zone.SensorType`, `Zone.RfSignal` and `Zone.BatteryLevel` enums. Each returns `None` when the bridge doesn't report it. `damper_fault` also works on V1
- `BattVolt` is decoded as the vendor's battery-level enum (full / half / empty), not volts
- Bridges without damper position feedback report a constant `DmpPos` of 50, so `damper_position` reads 50 on those units
- New controller properties: `airflow_lock`, `airflow_min_lock` and `system_locked`, which work on V1 and V2. V2 lock flags are normalized to the V1 `AirflowLock` / `UnitLocked` values
- New controller properties `indoor_humidity`, `indoor_tvoc` and `indoor_eco2`. These come from undocumented V2 keys (`InRh`, `InTVOC`, `IneCO2`), so their meaning and units are unverified

### Fixes

- A missing `CtrlZone` no longer falls back to zone 0. `zone_ctrl` is now `int | None`, and `control_setpoint_owner` returns `None` when it is unknown
- `CtrlZone` 15 (unit setpoint, per the vendor header) now gives the unit ownership in every RAS mode, not only master

### Maintenance

- Dependency lock bumps: aiohttp 3.14.4, multidict 6.9.1
