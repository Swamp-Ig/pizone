# Release notes — v1.3.8

**Compare range:** https://github.com/Swamp-Ig/pizone/compare/v1.3.7...v1.3.8

## Since v1.3.7

- `discover_all` skips controllers that become claimed mid-scan (`ControllerAlreadyClaimedError`) instead of failing the scan
- Expected UDP `sendto` failures (blocked broadcast / interface down) log at debug instead of warning with a traceback
- Drop dead `RuntimeError` suppress around UDP `_cache_endpoint` (claimed endpoints already return earlier; that path raises `ControllerAlreadyClaimedError`)
