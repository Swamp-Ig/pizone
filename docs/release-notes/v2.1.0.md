# Release notes — v2.1.0

**Compare range:** https://github.com/Swamp-Ig/pizone/compare/v2.0.1...v2.1.0

## Since v2.0.1

### Reprogrammed systems are detected

- If an installer reprograms the system (zone count, zone types or fan setup), refreshes and commands now raise the new `DeviceReconfigurationError` instead of carrying on with the old layout. Its `changes` attribute lists what changed.
- To recover, close the controller and create a new one with `DiscoveryService.create_controller()`.
- `DeviceReconfigurationError` is not a `ConnectionError`, so existing outage handling won't catch it. Callers should catch it and recreate the controller.
