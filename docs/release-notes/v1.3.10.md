# Release notes — v1.3.10

**Compare range:** https://github.com/Swamp-Ig/pizone/compare/v1.3.9...v1.3.10

## Since v1.3.9

### Control setpoint (new)

- `Controller.control_setpoint_owner` — the controller, the matching zone, or `None` for who owns the unit target. RAS mode, master with CtrlZone past the configured zone count, or a missing AUTO CTS selects the controller. CONST/OPCL `Temp:0` does not.
- `Controller.control_setpoint` — that owner's setpoint (°C)

### Fixes / hardening

- Drop the `Connection: close` / `force_close` HTTP keepalive workaround (core#176536)
- Require `aiohttp>=3.14.3` for CVE-2026-69244
